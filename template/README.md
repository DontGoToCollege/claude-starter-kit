# claude-rules

My rules for Claude, made with the [Claude starter kit](https://github.com/DontGoToCollege/claude-starter-kit). Private: only I can see this.

| File | What it's for |
|---|---|
| `CLAUDE.md` | My rules: how Claude works for me |
| `settings.json` | My projects folder, public or private for new projects, and things Claude must never touch (`handsOff`) |
| `plugins.json` | The Claude plugins and tools every computer of mine gets, each on (`true`) or off (`false`) |
| `Versions/Archive/` | Every version of my rules |

To change any of it, ask Claude in a chat, for example *"add my Taxes folder to my hands-off list"*. Claude edits the file, raises the rules version and publishes it.

On a new computer, double-click `Setup.cmd` from the [starter kit's latest release](https://github.com/DontGoToCollege/claude-starter-kit/releases/latest).
